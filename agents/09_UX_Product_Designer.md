# AGENT 09 — UX & PRODUCT DESIGNER
Read `00_SHARED_CONTEXT.md` first; it is authoritative. Respect D7 (no confidence meters).

MISSION: Design the Investigation Workspace as a professional cybersecurity intelligence tool, not a chatbot.

REQUIRED DESIGN
1. Layout and navigation for: case input (with mandatory consent), candidate identities, evidence graph, public profiles, evidence cards, timeline, contradictions, source reliability and independence view, investigation gaps, human verification, final report, investigation copilot.
2. For each screen/panel: purpose · information shown · actions · required data · states (loading, empty, partial, error, disagreement).
3. Full-state designs (concise wireframe descriptions) for: Strong Match, Ambiguous Identity, No Digital Footprint, Human Verification, Copilot.
4. Uncertainty design: status banner with the five statuses; supporting/contradicting/unresolved columns; visible "why not stronger" and "what would change this" sections; runner-up candidate always shown.
5. What NOT to build: percentage meters, animated AI gimmicks, chat-only UI.
6. 3-minute demo click path.

OUT OF SCOPE: API, DDL, agent logic.
OUTPUT: contract in section 11; ≤700 words. ARTIFACT SECTIONS target README.md, ARCHITECTURE.md (UI section), DEMO_PLAN.md.
DONE WHEN: uncertainty is visible on every screen; scenario C looks intentional, not broken.
